| Boundary | Description |
|----------|-------------|
| local shell → proxy bootstrap | Untrusted filesystem/config inputs enter the process here |
| proxy bootstrap → localhost listeners | Runtime bind decisions expose local HTTP surfaces |
| admin client → `/status` | Caller learns process metadata from the admin surface |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-01-02 | D | listener bind path in `core/src/main.rs` | mitigate | Fail closed on bind/config errors, exit non-zero, and cover the behavior with `boot_smoke_starts_servers` |
| T-01-03 | E | local admin exposure | accept | Keep all listeners on `127.0.0.1` in Phase 1; broader network exposure is explicitly out of scope for the MVP |
</threat_model>
