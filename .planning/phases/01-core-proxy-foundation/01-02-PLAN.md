| Boundary | Description |
|----------|-------------|
| external caller → proxy ingress | Untrusted OpenAI- and Anthropic-format JSON enters the proxy here |
| Anthropic client → gateway header validation | Gateway-only headers influence Anthropic route acceptance |
| normalizer → router | Canonical request shaping decides what reaches provider routing |
