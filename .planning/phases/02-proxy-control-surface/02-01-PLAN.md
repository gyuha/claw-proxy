<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer-supplied proxy settings -> Rust validation helpers | Untrusted input crosses into a local network binding decision |
| Rust proxy supervisor -> local network interface | Host code decides whether the proxy is reachable beyond loopback |
| proxy supervisor state -> UI-facing snapshot contracts | Runtime truth is serialized for renderer consumption |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | T | `src-tauri/src/models/proxy_settings.rs` | mitigate | Validate host, port, and base endpoint in Rust before any supervisor action; reject non-loopback hosts in Phase 2 |
| T-2-02 | I | `src-tauri/src/runtime/proxy_runtime.rs` | mitigate | Default to `127.0.0.1`, expose only loopback-safe binds, and never infer LAN exposure silently |
| T-2-03 | D | `src-tauri/src/runtime/state.rs` | mitigate | Serialize supervisor transitions through host-owned state and clear stale task handles on failed starts/stops |
</threat_model>
