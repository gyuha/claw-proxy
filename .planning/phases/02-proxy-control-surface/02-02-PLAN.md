<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer command payloads -> proxy settings apply pipeline | Untrusted UI input requests persistence and listener reconfiguration |
| persistence layer -> local config database | Host code writes durable configuration that affects local network behavior |
| lifecycle commands -> event emission | State changes are broadcast to the renderer through Tauri events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-04 | T | `src-tauri/src/commands/proxy.rs` | mitigate | Accept only typed settings payloads, re-run Rust validation server-side, and reject renderer-side file or SQL editing paths |
| T-2-05 | R | `src-tauri/src/runtime/persistence.rs` | mitigate | Persist a single canonical row with `updated_at` so applied settings changes are durable and auditable in-app |
| T-2-06 | D | `src-tauri/src/commands/proxy.rs` | mitigate | Attempt start/restart before persisting candidate settings and preserve last known good config when apply fails |
</threat_model>
