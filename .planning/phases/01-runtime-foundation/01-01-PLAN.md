## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI renderer -> Tauri command layer | Untrusted UI input crosses into the runtime host |
| Local build scripts -> desktop bundle | Tooling and package configuration affect what code ships |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | T | `src-tauri/src/lib.rs` command registration | mitigate | Keep runtime authority in Rust and add only explicit commands/events |
| T-1-02 | I | `package.json` / tooling scripts | mitigate | Keep dependency surface narrow and avoid secret-handling packages in Phase 1 |
| T-1-03 | E | renderer bootstrap | mitigate | Do not introduce direct secret access or implicit runtime mutability from the renderer |
</threat_model>
