## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> Tauri commands | Untrusted renderer actions can request runtime changes or data |
| runtime state -> serialized snapshot | Internal host state crosses into UI-safe serialized data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-04 | T | runtime commands | mitigate | Expose only named commands with narrow payloads and typed models |
| T-1-05 | I | serialized runtime snapshot | mitigate | Exclude secrets and internal-only fields from serialized snapshot structs |
| T-1-06 | E | renderer-owned state drift | mitigate | Keep snapshot writes in Rust state container and limit renderer to explicit command calls |
</threat_model>
